# SauceDemo-Test-Script-and-Bug-Report
Automated Playwright tests &amp; bug report for SauceDemo (saucedemo.com), a demo e-commerce site for QA practice. Covers login, cart, sorting, and checkout flows, plus beginner-friendly bug writeups for the site’s intentionally broken test accounts (problem_user, error_user, and more). Great for learning test automation basics.
